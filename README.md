# signal-dock

> Lightweight infrastructure monitoring for small teams.

signal-dock is a minimal monitoring dashboard designed for developers who need simple infrastructure visibility without enterprise complexity.

The project focused on real-time service health, deployment tracking, and lightweight observability tooling.

---

## Why I Built This

Most monitoring platforms felt overloaded for smaller projects.

I wanted something cleaner:
- fast setup
- readable dashboards
- simple uptime tracking
- lightweight deployment visibility

The goal was to create a focused developer experience instead of another bloated admin panel.

---

## Stack

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Recharts
